🎯 First Time Setup (5 minutes)

Step 1: Get your Anthropic API key from console.anthropic.com
Step 2: Copy the file .env.example and rename it to .env
Step 3: Open .env with a text editor and paste your API key
Step 4: Open terminal/command prompt in this folder and run:
npm run build
⚠️ Important: You MUST complete the setup above before using the app for the first time!

🚀 How to Start Writing (Every Time)

Simply double-click the appropriate file for your operating system:

Your browser will automatically open to http://localhost:3000

✅ Quick Checklist

  • Added API key to .env file
  • Ran npm run build
  • Know which startup file to use (Windows/Mac/Linux)
  • Ready to write your book!

💡 Pro Tips

Bookmark: Save http://localhost:3000 in your browser
Backup: Use "Export to JSON" regularly to save your work
Dark Mode: Click "Night Mode" button for easier night writing
Keep Terminal Open: Don't close the terminal window while writing
